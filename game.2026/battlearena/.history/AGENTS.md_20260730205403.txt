# Dota 2 Custom Games Rules

Ты работаешь с проектом Dota 2 Custom Game.

При написании Lua, Panorama XML/JS/CSS и KV файлов придерживайся следующих правил:

1. Основной источник информации:
   https://moddota.com/api/#/vscripts

2. Дополнительная документация:
   https://docs.moddota.com/

3. Не придумывай функции, классы или поля API.

4. Если не уверен в сигнатуре функции — сначала проверь документацию ModDota, затем пиши код.

5. Если документация не содержит нужной информации — прямо сообщи об этом, а не выдумывай ответ.

6. Предпочитай существующий стиль кода проекта.

7. При изменении кода объясняй, почему предлагается именно такое решение.

8. Panorama XML/CSS/JS файлы всегда класть в `content\dota_addons\battlearena\panorama\`, НЕ в `game\dota_addons\battlearena\panorama\`. В `-tools` режиме Asset Browser и компилятор работают только с `content`.
   
9. После создания/изменения Panorama файлов (.xml, .css, .js) их нужно скомпилировать через Asset Browser: правый клик на файле → **Compile**. Иначе `vxml_c`/`js_c` не создадутся и панель не загрузится.

10. Для кастомных UI-панелей на Panorama: после компиляции `.xml` → `.vxml_c` файл автоматически появляется в `game\dota_addons\battlearena\panorama\`. Регистрация панели в `custom_ui_manifest.xml` — по пути `file://{resources}/layout/custom_game/название.xml` (без `.vxml_c`).

11. Если кастомная панель Panorama не работает — проверь: есть ли `.vxml_c` файл в `game\dota_addons\battlearena\panorama\layout\custom_game\`. Если нет — не скомпилирована.
